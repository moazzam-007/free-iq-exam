    <section class="space-y-6">
      <h2 class="font-heading text-2xl sm:text-3xl font-bold text-zinc-950 dark:text-white">
        The Normal Distribution &amp; Bell Curve Mechanics
      </h2>
      <div class="prose dark:prose-invert max-w-none text-sm sm:text-base text-zinc-600 dark:text-zinc-300 space-y-4 leading-relaxed">
        <p>
          All modern IQ assessments are <strong>deviation IQ tests</strong>. Pioneered by David Wechsler in 1939 to replace William Stern's outdated ratio concept (Mental Age divided by Chronological Age multiplied by 100), deviation IQ anchors performance directly to a Gaussian normal distribution.
        </p>
        <p>
          In a standardized deviation IQ model:
        </p>
        <ul class="space-y-2 list-disc pl-5">
          <li><strong>The Mean (&mu;) is fixed at 100:</strong> The median score of any representative age-matched population cohort is defined as 100.</li>
          <li><strong>The Standard Deviation (&sigma;) is set to 15:</strong> One standard deviation represents 15 IQ points on the Wechsler and Stanford-Binet 5 scales.</li>
          <li><strong>The 68-95-99.7 Rule:</strong> Exactly 68.26% of human scores fall within &plusmn;1 standard deviation (IQ 85 to 115). Exactly 95.44% fall within &plusmn;2 standard deviations (IQ 70 to 130). Exactly 99.73% fall within &plusmn;3 standard deviations (IQ 55 to 145).</li>
        </ul>
      </div>

      <h2 class="font-heading font-bold text-xl sm:text-2xl text-zinc-950 dark:text-white">
        The Flynn Effect &amp; Generational Norm Recalibration
      </h2>
      <p class="text-xs sm:text-sm text-zinc-600 dark:text-zinc-300 leading-relaxed">
        Discovered by political scientist James R. Flynn, the <strong>Flynn Effect</strong> observes that raw scores on intelligence tests increased at an average rate of approximately 3 IQ points per decade throughout the 20th century across industrialized nations.
      </p>
      <p class="text-xs sm:text-sm text-zinc-600 dark:text-zinc-300 leading-relaxed">
        Because of this generational upward shift in raw problem-solving speed and visual abstraction, an individual who scored 100 on an exam normed in 1950 would score noticeably lower on a test calibrated to 2026 norms. To prevent artificial inflation of cognitive classifications, psychometric publishers restandardize their normative test samples every 10 to 15 years.
      </p>
    </section>

  function erf(x: number): number {
    const sign = x >= 0 ? 1 : -1;
    const absX = Math.abs(x);
    const a1 = 0.254829592;
    const a2 = -0.284496736;
    const a3 = 1.421413741;
    const a4 = -1.453152027;
    const a5 = 1.061405429;
    const p = 0.3275911;
    const t = 1.0 / (1.0 + p * absX);
    const y = 1.0 - (((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t) * Math.exp(-absX * absX);
    return sign * y;
  }

  function normalCdf(z: number): number {
    return 0.5 * (1.0 + erf(z / Math.SQRT2));
  }

      // Error function approximation for cumulative normal distribution
      function erf(x) {
        const a1 = 0.254829592, a2 = -0.284496736, a3 = 1.421413741;
        const a4 = -1.453152027, a5 = 1.061405429, p = 0.3275911;
        const sign = x < 0 ? -1 : 1;
        x = Math.abs(x);
        const t = 1.0 / (1.0 + p * x);
        const y = 1.0 - (((((a5 * t + a4) * t) + a3) * t + a2) * t + a1) * t * Math.exp(-x * x);
        return sign * y;
      }

      function update(score) {
        slider.value = score;
        input.value = score;

        const z = (score - 100) / 15;
        const cdf = 0.5 * (1 + erf(z / Math.SQRT2));
        const pct = Math.min(99.999, Math.max(0.001, cdf * 100));
        const topFraction = 1 - cdf;
        const freqRatio = topFraction > 0 ? Math.round(1 / topFraction) : 1000000;

        displayPct.textContent = pct >= 99.9 ? pct.toFixed(2) + 'th Percentile' : pct.toFixed(1) + 'th Percentile';
        displayFreq.textContent = '1 in ' + freqRatio.toLocaleString() + ' people';

        // Render society qualifications
        listEl.innerHTML = societyData.map(s => {
          const qualified = score >= s.minIQ;
          const diff = s.minIQ - score;
          let statusHtml = '';

          if (qualified) {
            statusHtml = '<span class="px-2 py-0.5 rounded text-[11px] font-semibold bg-emerald-100 dark:bg-emerald-950/70 text-emerald-800 dark:text-emerald-300">Qualifies (Score ' + score + ' >= ' + s.minIQ + ')</span>';

      </h3>
      <p class="mb-3">
        The conversion from standard score to percentile operates through standard normal standardization:
      </p>
      <div class="p-4 rounded-xl bg-white dark:bg-zinc-900 border border-zinc-200 dark:border-zinc-800 font-mono text-xs mb-3">
        z = (IQ - 100) / 15<br />
        Percentile = &Phi;(z) &times; 100 = 0.5 &times; [1 + erf(z / &radic;2)] &times; 100
      </div>
      <p>
        Where &Phi; is the cumulative distribution function of the standard normal distribution, and erf is the Gauss error function.

  // Mathematical functions
  function erf(x: number): number {
    const sign = x >= 0 ? 1 : -1;
    const absX = Math.abs(x);
    const a1 = 0.254829592;
    const a2 = -0.284496736;
    const a3 = 1.421413741;
    const a4 = -1.453152027;
    const a5 = 1.061405429;
    const p = 0.3275911;
    const t = 1.0 / (1.0 + p * absX);
    const y = 1.0 - (((((a5 * t + a4) * t + a3) * t + a2) * t + a1) * t) * Math.exp(-absX * absX);
    return sign * y;
  }

  function normalCdf(z: number): number {
    return 0.5 * (1.0 + erf(z / Math.SQRT2));
  }

  // Inverse normal approximation (Beasley-Springer-Moro)
  function rationalApproximation(t: number): number {
    const c = [2.515517, 0.802853, 0.010328];
    const d = [1.432788, 0.189269, 0.001308];
    return t - ((c[2] * t + c[1]) * t + c[0]) / (((d[2] * t + d[1]) * t + d[0]) * t + 1.0);
  }

  function invNormalCdf(p: number): number {
    if (p <= 0) return -4.0;
    if (p >= 1) return 4.0;
    if (p < 0.5) {
      return -rationalApproximation(Math.sqrt(-2.0 * Math.log(p)));
    } else {
      return rationalApproximation(Math.sqrt(-2.0 * Math.log(1.0 - p)));
    }
  }

  document.addEventListener('DOMContentLoaded', () => {

      if (outputIqFromPct) outputIqFromPct.textContent = `${iq} IQ`;

          outputMensaStatus.className = 'text-xs font-semibold px-3 py-1 rounded-full bg-indigo-100 text-indigo-800 dark:bg-indigo-950 dark:text-indigo-300';
        } else {
          const ptsNeeded = Math.max(1, 130 - iq);
          outputMensaStatus.textContent = `Below 98th Percentile (Need +${ptsNeeded} IQ pts)`;
          outputMensaStatus.className = 'text-xs font-semibold px-3 py-1 rounded-full bg-zinc-100 text-zinc-700 dark:bg-zinc-800 dark:text-zinc-300';
        }
      }
    }

    if (pctInput && pctSlider) {
      pctInput.addEventListener('input', () => {
        const val = parseFloat(pctInput.value) || 50;
        pctSlider.value = String(val);
        updateFromPct(val);
      });
      pctSlider.addEventListener('input', () => {

        pctInput.value = String(val);
        updateFromPct(val);

    <!-- Section 2: Mathematical Formulation of 2PL IRT Model -->
    <section id="section-2-2pl" class="p-6 sm:p-8 rounded-3xl bg-white dark:bg-zinc-900 border border-zinc-200 dark:border-zinc-800 shadow-xs space-y-6">
      <div>
        <span class="text-xs font-mono font-semibold text-blue-600 dark:text-blue-400 uppercase tracking-wider block mb-2">
          Section 02
        </span>
        <h2 class="font-heading font-bold text-2xl sm:text-3xl text-zinc-950 dark:text-white mb-3">
          Mathematical Formulation of the 2-Parameter Logistic (2PL) Model
        </h2>
        <p class="text-sm sm:text-base text-zinc-600 dark:text-zinc-300 leading-relaxed">
          Classical Test Theory (CTT) treats every test item identically, scoring ability as an unweighted sum of correct responses. This creates severe sample dependency: raw scores cannot differentiate whether an examinee succeeded on trivial or exceptionally arduous items. FreeIQExam overcomes this limitation by implementing the 2-Parameter Logistic (2PL) Item Response Theory model.
        </p>
      </div>

      <!-- Formula Block -->
      <div class="p-5 sm:p-6 rounded-2xl bg-zinc-50 dark:bg-zinc-950 border border-zinc-200 dark:border-zinc-800 space-y-3">
        <div class="text-xs font-mono text-zinc-400 uppercase tracking-wider">The Standard 2PL IRT Equation</div>
        <div class="font-mono text-base sm:text-lg text-blue-600 dark:text-blue-400 font-bold overflow-x-auto py-1">
          P_i(&theta;) = 1 / [ 1 + exp( -1.702 &times; a_i &times; (&theta; - b_i) ) ]
        </div>
        <div class="text-xs sm:text-sm text-zinc-600 dark:text-zinc-300 leading-relaxed space-y-1.5 pt-2">
          <p>Where:</p>
          <ul class="list-disc list-inside space-y-1 pl-1">
            <li><strong>&theta; (Theta):</strong> The latent cognitive trait of the examinee, distributed along the standard normal continuum N(0, 1).</li>
            <li><strong>a_i (Discrimination):</strong> The slope of the Item Characteristic Curve (ICC) at the inflection point, characterizing how sharply the item differentiates between examinees above versus below the threshold.</li>
            <li><strong>b_i (Difficulty):</strong> The latent ability level at which the probability of a correct response is exactly 50% (P_i(&theta;) = 0.50).</li>
            <li><strong>D = 1.702:</strong> The normal ogive scaling constant ensuring mathematical concordance between the logistic metric and the cumulative normal distribution function &Phi;(z).</li>
          </ul>
        </div>
      </div>

    <!-- Section 3: Bayesian Expected A Posteriori (EAP) Estimation Engine -->
    <section id="section-3-eap" class="p-6 sm:p-8 rounded-3xl bg-white dark:bg-zinc-900 border border-zinc-200 dark:border-zinc-800 shadow-xs space-y-6">
      <div>
        <span class="text-xs font-mono font-semibold text-blue-600 dark:text-blue-400 uppercase tracking-wider block mb-2">
          Section 03
        </span>
        <h2 class="font-heading font-bold text-2xl sm:text-3xl text-zinc-950 dark:text-white mb-3">
          Bayesian Expected A Posteriori (EAP) Estimation Engine
        </h2>
        <p class="text-sm sm:text-base text-zinc-600 dark:text-zinc-300 leading-relaxed">
          While Maximum Likelihood Estimation (MLE) is widely used in long academic exams, it suffers from a catastrophic mathematical failure mode on short assessments: when an examinee scores 0 out of 24 (or 24 out of 24), the likelihood function is strictly monotonic, causing MLE to diverge to negative or positive infinity.
        </p>
      </div>

      <p class="text-sm sm:text-base text-zinc-600 dark:text-zinc-300 leading-relaxed">
        FreeIQExam solves this by implementing Bayesian Expected A Posteriori (EAP) estimation with a standardized Gaussian informative prior g(&theta;) ~ N(0, 1). This guarantees finite, robust, and regularized ability estimates regardless of response vector extremeness.
      </p>

      <!-- Numerical Quadrature Equation -->
      <div class="p-5 sm:p-6 rounded-2xl bg-zinc-50 dark:bg-zinc-950 border border-zinc-200 dark:border-zinc-800 space-y-3">
        <div class="text-xs font-mono text-zinc-400 uppercase tracking-wider">Gauss-Hermite Numerical Quadrature (81 Nodes)</div>
        <div class="font-mono text-sm sm:text-base text-blue-600 dark:text-blue-400 font-bold overflow-x-auto py-1">
          &theta;_hat_EAP = [ &Sigma;<sub>k=1..Q</sub> [ &theta;_k &times; L(&theta;_k | u) &times; W(&theta;_k) ] / &Sigma;<sub>k=1..Q</sub> [ L(&theta;_k | u) &times; W(&theta;_k) ]
        </div>
        <p class="text-xs sm:text-sm text-zinc-600 dark:text-zinc-300 leading-relaxed">
          The engine computes the integral across Q = 81 equidistant evaluation nodes spanning &theta;_k &isin; [-4.0, +4.0] with node step size &Delta;&theta; = 0.10. For any vector of binary item responses u = (u_1, u_2, ..., u_n), the response pattern likelihood is:
        </p>
        <div class="font-mono text-xs sm:text-sm text-zinc-800 dark:text-zinc-200 py-1">
          L(&theta;_k | u) = &prod;<sub>i=1..n</sub> [ P_i(&theta;_k)<sup>u_i</sup> &times; (1 - P_i(&theta;_k))<sup>1 - u_i</sup> ]
        </div>
        <p class="text-xs text-zinc-500 font-mono">
          Where prior weighting W(&theta;_k) = (1 / &radic;(2&pi;)) &times; exp(-&theta;_k^2 / 2) &times; &Delta;&theta;.
        </p>
      </div>

      <!-- Posterior Variance & 95% Credible Interval -->
      <div class="p-5 sm:p-6 rounded-2xl bg-zinc-50 dark:bg-zinc-950 border border-zinc-200 dark:border-zinc-800 space-y-3">
        <div class="text-xs font-mono text-zinc-400 uppercase tracking-wider">Conditional SEM & 95% Credible Interval</div>
        <p class="text-xs sm:text-sm text-zinc-600 dark:text-zinc-300 leading-relaxed">
          Unlike Classical Test Theory, which assumes an invariant standard error for all candidates, IRT models conditional measurement error across the trait continuum. The posterior variance is computed directly from the second moment of the posterior distribution:
        </p>
        <div class="font-mono text-xs sm:text-sm text-zinc-800 dark:text-zinc-200 py-1">
          Var(&theta; | u) = &Sigma;<sub>k=1..Q</sub> [ (&theta;_k - &theta;_hat_EAP)<sup>2</sup> &times; L(&theta;_k | u) &times; W(&theta;_k) ] / &Sigma;<sub>k=1..Q</sub> [ L(&theta;_k | u) &times; W(&theta;_k) ]
        </div>
        <div class="font-mono text-xs sm:text-sm text-indigo-600 dark:text-indigo-400 font-semibold py-1">
          SEM(&theta;) = &radic;Var(&theta; | u)
        </div>
        <p class="text-xs sm:text-sm text-zinc-600 dark:text-zinc-300 leading-relaxed">
          The 95% Posterior Credible Interval reported on candidate score certificates is formally derived as:
        </p>
        <div class="font-mono text-xs sm:text-sm text-blue-600 dark:text-blue-400 font-bold py-1">
          Interval<sub>95%</sub> = [ IQ - 1.96 &times; 15 &times; SEM(&theta;), &nbsp; IQ + 1.96 &times; 15 &times; SEM(&theta;) ]
        </div>
      </div>
    </section>

      <div>
        <span class="text-xs font-mono font-semibold text-blue-600 dark:text-blue-400 uppercase tracking-wider block mb-2">
          Section 04
        </span>
        <h2 class="font-heading font-bold text-2xl sm:text-3xl text-zinc-950 dark:text-white mb-3">
          Scale Standardization vs. Population Norming
        </h2>
        <p class="text-sm sm:text-base text-zinc-600 dark:text-zinc-300 leading-relaxed">
          A fundamental scientific requirement under the Standards for Educational and Psychological Testing (AERA, APA, NCME, 2014) is absolute transparency regarding how raw ability metrics are translated into standardized scores.
        </p>
      </div>

      <!-- Linear Transformation Formula -->
      <div class="p-5 rounded-2xl bg-zinc-50 dark:bg-zinc-950 border border-zinc-200 dark:border-zinc-800">
        <span class="text-xs font-mono text-zinc-400 uppercase tracking-wider block mb-1">Standardized Linear Transformation</span>
        <div class="font-mono text-base sm:text-lg font-bold text-blue-600 dark:text-blue-400 mb-2">
          Standardized Score = round( 100 + 15 &times; &theta;_hat_EAP )
        </div>
        <p class="text-xs sm:text-sm text-zinc-600 dark:text-zinc-300 leading-relaxed">
          Percentiles are calculated via the standard normal cumulative distribution function &Phi;(z):
        </p>
        <div class="font-mono text-xs sm:text-sm text-zinc-800 dark:text-zinc-200 mt-1">
          Percentile = &Phi;( (Standardized Score - 100) / 15 ) &times; 100%
        </div>
      </div>

      <!-- Critical Distinction Card -->
      <div class="p-5 sm:p-6 rounded-2xl bg-amber-50/70 dark:bg-amber-950/30 border border-amber-200 dark:border-amber-900 text-xs sm:text-sm text-amber-950 dark:text-amber-200 leading-relaxed space-y-3">
        <h3 class="font-heading font-bold text-base uppercase tracking-wider text-amber-900 dark:text-amber-300">
          Scientific Clarification: Scale Metric vs. Clinical Population Norms
        </h3>
        <p>
          1. <strong>Scale Transformation:</strong> FreeIQExam projects latent trait theta (&theta;) onto the classical Wechsler/Stanford-Binet metric (Mean = 100, SD = 15). This provides a universally recognized reference scale for relative cognitive performance.
        </p>
        <p>
          2. <strong>Empirical Population Norms:</strong> Establishing formal demographic population norms requires stratified sampling across thousands of clinical subjects segmented by age, geographic region, and educational attainment. FreeIQExam does not claim clinical diagnosis; our scores reflect mathematically rigorous 2PL IRT estimates anchored to verified open-science benchmarks.
        </p>
      </div>
    </section>

        <h2 class="font-heading font-bold text-2xl sm:text-3xl text-zinc-950 dark:text-white mb-3">
          Sub-Domain Reporting Rationale
        </h2>
        <p class="text-sm sm:text-base text-zinc-600 dark:text-zinc-300 leading-relaxed">
          In the 24-item Full Assessment, examinees complete 6 items per cognitive domain (Fluid, Spatial, Quantitative, Verbal). A common pitfall in commercial online testing is reporting continuous IQ sub-scores for short sub-tests (e.g. claiming "Spatial IQ = 138" based on 6 items).
        </p>
      </div>

      <div class="p-5 rounded-2xl bg-zinc-50 dark:bg-zinc-950 border border-zinc-200 dark:border-zinc-800 space-y-3">
        <h3 class="font-heading font-bold text-base text-zinc-950 dark:text-white">
          The Problem of Wide Conditional Standard Errors on Short Vectors
        </h3>
        <p class="text-xs sm:text-sm text-zinc-600 dark:text-zinc-300 leading-relaxed">
          On a 6-item domain vector, the conditional standard error of measurement is wide (SEM &approx; 0.45 to 0.65 &theta;, equivalent to &plusmn;7 to &plusmn;10 IQ points). Producing continuous pseudo-precise sub-scores produces spurious precision that misleads candidates and violates psychometric reporting standards.
        </p>
        <p class="text-xs sm:text-sm text-zinc-600 dark:text-zinc-300 leading-relaxed">
          FreeIQExam adopts a conservative, scientifically defensible solution:
        </p>
        <ul class="list-disc list-inside text-xs sm:text-sm text-zinc-700 dark:text-zinc-300 space-y-1 pl-1">
          <li><strong>Domain Accuracy Ratios:</strong> We report raw performance (e.g., "5 / 6 Correct, 83%").</li>
          <li><strong>Qualitative Performance Tiers:</strong> Performance is mapped into descriptive bands:
            <span class="font-mono text-xs font-semibold text-blue-600 dark:text-blue-400">Strength Area (&ge;83%)</span>,
            <span class="font-mono text-xs font-semibold text-indigo-600 dark:text-indigo-400">High Average (67-82%)</span>,
            <span class="font-mono text-xs font-semibold text-zinc-700 dark:text-zinc-300">Average Range (50-66%)</span>, and
            <span class="font-mono text-xs font-semibold text-amber-600 dark:text-amber-400">Developing Area (&lt;50%)</span>.
          </li>
          <li><strong>Dedicated 20-Item Tests:</strong> For candidates seeking continuous psychometric sub-scale precision, FreeIQExam provides four dedicated 20-item single-domain test batteries where measurement error is constrained to acceptable limits.</li>
        </ul>
      </div>

          </p>

            Mentally Unrolling 3D Cube Nets
