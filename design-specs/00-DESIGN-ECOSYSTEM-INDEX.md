## 🛠️ Mandatory Agent Workflow
Before implementing or modifying ANY frontend UI:
1. **Read `SOVEREIGN_UNIVERSAL_LAW.md`**: Enforce Commit `857dc4b` and conflict guard.
2. **Read `01-DESIGN_SYSTEM_RULES.md` & `ANTI_AI_UI_RULES.md`**.
3. **Read `ASTRO_RULES.md` & `ACCESSIBILITY_RULES.md`**.
4. **Inspect existing components and tokens before creating new markup**.
5. **Implement the smallest consistent change**.
6. **Run the Pre-Delivery Anti-Slop Audit Checklist**.
7. **Rule Integrity**: Never modify rule files to make a bad implementation pass.
