### 🛡️ FIVE CORE AUDIT PILLARS & CRITERIA

#### Pillar 1: Client Privacy, Zero-Telemetry & Clinical Confidentiality
- **Zero Data Leakage**: Ensure diagnostic screeners (ADHD, Depression, Anxiety, Autism, Eye, Hearing) NEVER transmit user answers, scores, or session IDs over network requests.
- **Client-Side Storage**: Check all `localStorage` usage (e.g. `coc_items_v1`, theme preferences). Verify graceful degradation when private browsing mode or storage quotas throw errors.
- **Data Sanitization**: Ensure dynamic user text inputs (e.g. custom worries in Circle of Control, notes in Memento Mori) are properly escaped before DOM injection to prevent XSS.

#### Pillar 2: Memory Lifecycle, Canvas Physics & Web Audio API Cleanups
- **Web Audio Contexts**: Verify `AudioContext` states (`suspended` vs `running`), ensure oscillators, buffer sources, and filter nodes are explicitly stopped and disconnected on tool resets or navigation.
- **Canvas `requestAnimationFrame` Loops**: Verify `cancelAnimationFrame` is called on tab blur, tool reset, or unmount to prevent background CPU/battery drain.
- **Timers & Event Listeners**: Check for orphan `setInterval`, `setTimeout`, and window resize listeners that could cause memory bloat during prolonged sessions.

#### Pillar 3: Internal Link Architecture, Discoverability & PageRank Distribution
- **Homepage Integration (`/index.astro`)**:
  * Are all 17 newly built diagnostic, cognitive, circadian, and stoic tools discoverable from the main homepage?
  * Map out the tool showcase cards and featured sections to ensure no high-value tools are hidden.
- **Category Hubs (`/test`, `/tools`, `/games`)**:
  * Verify that parent index pages properly list, categorize, and link to all child tools with correct URLs.
- **Header & Footer Navigation Synchronization**:
  * Cross-reference `src/components/Header.astro` (desktop flyouts, mobile accordion sections) and `src/components/Footer.astro` (4 categorized columns).
  * Identify any orphan routes, mismatched URLs, dead redirects, or missing tools.

#### Pillar 4: Canonical Consistency, Meta Headers & JSON-LD Structured Data
- **Canonical URLs**: Verify that `canonicalUrl` in every `.astro` frontmatter exactly matches the production path (e.g. `https://freeiqexam.com/sleep-calculator` with zero trailing slash discrepancies).
- **JSON-LD Schema Verification**:
  * Check `@type`: `WebApplication`, `MedicalWebPage`, `BreadcrumbList`, `Quiz`, and `FAQPage`.
  * Verify aggregate ratings, feature lists, and FAQ question-answer arrays for validity against Google Rich Results standards.
- **OpenGraph & Twitter Card Metadata**: Verify `og:title`, `og:description`, `og:image`, and Twitter card tags are consistently populated across all tools.

#### Pillar 5: JavaScript Ergonomics & Cross-Browser Stability
- Ensure vanilla JavaScript logic avoids unsupported modern APIs without polyfills/fallbacks (e.g., `StereoPannerNode` channel merger fallback in Web Audio, Pointer Events vs Touch Events in Aim Trainer, DPR scaling in Canvas).
