### 📦 FILE 1 SPECIFICATIONS: `src/scripts/tools/eye-tester.js`
This file must be a modular, self-executing Vanilla JavaScript optometric engine:
1. **Module 1: Physical Screen Calibration (Credit Card Standard):**
   - Essential for optometric validity: standard Snellen optotypes must subtend exactly 5 arcminutes at testing distance.
   - Interactive on-screen card slider adjusts to match a standard physical credit card / driver's license (ISO/IEC 7810 ID-1 standard: exactly 85.60 mm width).
   - Computes exact device `pixelsPerMm = cardWidthInPixels / 85.60`.
   - Distance selector: 1 meter (~3.3 feet) for laptop/desktop or 40 cm (16 inches) for mobile reading distance.
   - Automatically computes optotype physical height in pixels: `heightMm = 2 * distanceMm * tan(5 arcmin / 2)`.
2. **Module 2: Visual Acuity Test (Tumbling E Standard):**
   - Uses the international standard "Tumbling E" optotype in 4 rotations (Up, Right, Down, Left), eliminating language/literacy bias.
   - Stepped acuity tiers: 20/200 -> 20/100 -> 20/70 -> 20/50 -> 20/40 -> 20/30 -> 20/25 -> 20/20 -> 20/15.
   - Adaptive staircase rule: 3 out of 4 correct responses required to advance to the next sharper tier.
   - Supports Left Eye, Right Eye, and Both Eyes testing workflow with clear instructions to cover one eye without pressing on the eyelid.
   - Controls: Arrow keys (`↑ ↓ ← →`) or tactile on-screen directional buttons.
3. **Module 3: Astigmatism Clock / Fan Dial:**
   - Renders a high-contrast radiating black starburst/fan dial with lines spaced at 15-degree / 30-degree clock positions (1 to 12).
   - Clinical Principle: Uncorrected corneal astigmatism causes focal line asymmetry; rays along the meridian of maximum refractive power appear noticeably darker, bolder, or sharper than perpendicular rays.
   - Interactive selector: User indicates whether all lines look identical, or selects which specific clock numbers appear darker or distorted.
4. **Module 4: Red-Green Duochrome Test (Refraction Balance):**
   - Side-by-side or split high-contrast Red (650 nm) and Green (535 nm) panels containing identical black optotypes.
   - Optical Principle (Longitudinal Chromatic Aberration):
     - Green wavelengths focus in front of retina; Red wavelengths focus behind retina.
     - If Red letters appear sharper -> Myopic shift / undercorrected nearsightedness.
     - If Green letters appear sharper -> Hyperopic shift / overcorrected farsightedness.
     - If both appear equally sharp -> Emmetropic refractive balance.
5. **Results & Clinician Scorecard:**
   - Displays Visual Acuity fraction (e.g. 20/20), Astigmatism assessment, and Refraction balance indicator.
   - Clinician summary printout (`window.print()`).
   - Clear Optometric Disclaimer: Preliminary screening; not a replacement for a dilated comprehensive exam by an optometrist or ophthalmologist.
